# Taste

- Communicates in Chinese, in a casual/terse register (short questions, trailing parentheses). Confidence: 0.8
- Impatient with slow progress — will interrupt both to switch methods and to prod the agent onward when a task drags, so favor fast, pragmatic setups over heavyweight/complete-but-slow ones. Confidence: 0.7
- Expects the agent to keep driving a task to completion on its own; when progress appears stalled or silent he pings to ask what's wrong and tells the agent to continue. Confidence: 0.55
- Prefers large/breaking changes be done in an isolated git worktree so the main working tree stays clean and buildable, rather than accumulating a half-converted state on main. Confidence: 0.65
- Wants visibility into what the agent is doing — dislikes long stretches where nothing is shown, and prefers work be broken into smaller visible steps (e.g. writing a large file in sections) rather than one big opaque operation. Confidence: 0.6
